# LinkedIn announcement — Open Cowork

Repo: https://github.com/fedollo/open-cowork

---

I open-sourced Open Cowork — a local web mini-app for agentic workspaces.

Pick a folder on disk, describe a goal in natural language, and an agent works on your files. The UI shows chat, a file tree, and live activity (SSE stream). It also supports Gauntlet mode: goal + concrete quality bar → builder/critic loop.

Stack: TypeScript, Vite + React, Hono, pnpm monorepo. Agent runtime: Cursor Agent SDK (`@cursor/sdk`) — independent project, not affiliated with Cursor. MIT. Everyone brings their own API key.

Why open source: this isn’t a commercial product — it’s a tool to fork and improve with the community.
